# sheepylove-mcu

Code for a MCU based relay (ATtiny412) and latching relay (5V). Things can always be improved but sharing is learning, enjoy.

* Config: platformio.ini
* Code: src/main.cpp

I use a [UPDI Friend](https://www.adafruit.com/product/5879) on macOS to upload to PCBs via [PlatformIO](https://platformio.org/). There are many ways to do it, explore!

It would be trivial to make this multi-channel capable if you have enough outputs on your MCU.
