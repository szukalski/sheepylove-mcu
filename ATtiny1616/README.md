# sheepylove-mcu

Code for a MCU based dual relay (ATtiny1616) and latching relay (5V). Things can always be improved but sharing is freedom, enjoy.

* Config: platformio.ini
* Code: src/main.cpp

I use a [UPDI Friend](https://www.adafruit.com/product/5879) on macOS to upload to PCBs via [PlatformIO](https://platformio.org/). There are many ways to do it, explore!
